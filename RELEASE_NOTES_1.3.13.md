# DropForge 1.3.13 (Tauri)

## Запуск старой копии

- Приложение определяет, что запущена не установленная копия (например, старый портативный архив из `Downloads`), и показывает предупреждение:
  «Запущена устаревшая копия приложения» + путь к установленной версии.
- Кнопка «Запустить установленную» открывает актуальный `dropforge-tauri.exe` из `%LOCALAPPDATA%\DropForge` и закрывает старую копию.
- При старте установленной версии подчищается дубликат `DropForge.exe` рядом с exe и вторая установка в `%LOCALAPPDATA%\Programs\DropForge`.

## Прогресс по GTA VI

- Минуты из тика вотчера теперь сохраняются в `progress.json` (`watch`), даже если кампании нет в публичном каталоге.
- В диагностике вместо «нет данных по играм из очереди» появляется строка `watch progress: <игра> — N мин`.
- В интерфейсе эти минуты не показываются.
