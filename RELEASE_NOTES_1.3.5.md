# DropForge 1.3.5

Исправлен выбор канала для кампаний со списком стримеров.

## Что было не так

Если у кампании есть список разрешённых каналов (например, Caliber: `kodolov_`, `sk_explorer`, `13raum13`, `basist_games`, `demon_lestat_yt`), приложение проверяло только первый канал из списка. Если он офлайн — фарм падал, а при пустом списке живых программа подставляла **любой** живой стрим категории, который к кампании не относится: минуты не засчитывались.

## Что исправлено

- Каналы из списка проверяются пачками по 20 на «в эфире ли сейчас» и берётся первый живой.
- Если список есть, но никто не в эфире — приложение больше не подменяет канал чужим и пишет в журнал: «нет живых каналов: у кампании свой список стримеров, сейчас никто не в эфире».
- Если кампания не ограничена списком — поведение прежнее (Drops-каналы, затем любые живые в категории).

## Проверка

Caliber (`caliber`): все 5 разрешённых каналов сейчас офлайн → фарм не запустится, в журнале будет понятная причина. Как только кто-то из них выйдет в эфир — заработает.
