# DropForge

Открытый аналог автофарма Twitch Drops для Windows: смотрит стримы вместо вас, забирает награды, показывает бейджи профиля и следит за прогрессом.

Написано на Rust (Tauri 2) — без Electron-обвязки, без скачивания видео: приложение запрашивает плейлист и сегменты потоков, отправляет события просмотра и забирает награды через API Twitch.

## Возможности

- **Автофарм дропсов** — выбираете игры, приложение само находит стрим с включёнными Drops и смотрит его.
- **Автовыдача** — как только награда стала доступна, она забирается автоматически.
- **Локальные дропсы каналов** — кампании, которые Twitch отдаёт только на конкретном канале.
- **Вкладка «Бейджи»** — значки профиля Twitch: бесплатные и платные, с пометкой «получен», кнопкой фарма и переходом в категорию.
- **Очередь игр** — переключение между играми, приоритет «скоро заканчивается».
- **Трей** — закрытие окна сворачивает приложение, а не выключает.
- **Диагностика** — один клик собирает отчёт о состоянии для разбора проблем (без личных данных).
- **Обновления** — кнопка проверки обновлений на GitHub Releases, скачивание и установка.

## Установка

1. Скачайте последний релиз со страницы [Releases](../../releases/latest):
   - `DropForge-<версия>-win64.zip` — портативная версия, ничего не устанавливает;
   - `DropForge_<версия>_x64-setup.exe` — установщик для текущего пользователя (без прав администратора).
2. Распакуйте/запустите `DropForge.exe`.
3. Войдите через Twitch: кнопка «Войти через Twitch» открывает браузер, пароль приложение не видит.

Требования: Windows 10/11, WebView2 (в системе по умолчанию).

Данные лежат рядом с программой в `data/`: настройки, кэш каталога и зашифрованный токен сессии.

## Сборка из исходников

Нужно: Rust stable (MSVC toolchain), Node.js 20+, WebView2.

```bash
npm install
npm run tauri:build            # release-сборка приложения
node scripts/build-tauri.mjs   # раскладка портативной папки в dist-tauri/
```

Установщик:

```bash
cd rust/tauri-app
npx tauri build --bundles nsis
```

## Структура

```
rust/tauri-app/     основное приложение (Tauri 2, Rust) + встроенный интерфейс
rust/watcher-svc/   сервис просмотра: плейлист → сегменты → события просмотра
rust/pubsub-svc/    слушает PubSub Twitch (живой прогресс дропсов)
src/ui/             интерфейс: HTML/CSS/JS без сборщика
scripts/            сборка, упаковка, релиз
docs/               заметки по идеям и исследованиям
```

## Безопасность

Кратко: токен хранится зашифрованным (DPAPI), в командной строке не передаётся, ссылки открываются без командной оболочки, интерфейс работает с CSP, отладочные хуки в релизе отключены. Подробнее — [SECURITY.md](SECURITY.md).

Ограничения: код не подписан (SmartScreen может предупреждать), автообновление доверяет GitHub Releases этого репозитория.

## Если что-то не работает

1. **Настройки → Обслуживание → «Собрать отчёт»** — создаст `data/profile/diagnostics/latest.txt`: версия, ОС, WebView2, наличие сервисов, статус входа, журнал, доступность Twitch и GitHub. Логин, токен и пути с именем пользователя в отчёт не попадают. Приложите этот файл к описанию проблемы.
2. **Проверьте, что запущена одна копия.** Две установки (портативная и установщик) конфликтуют: вторая молча закрывается. Оставьте одну.
3. **WebView2.** На старых сборках Windows 10 его может не быть — поставьте «Evergreen Runtime» от Microsoft.
4. **Антивирус.** Файлы не подписаны, поэтому эвристики (особенно Bkav) иногда помечают архив. Сверяйте SHA256 из описания релиза.
5. **Нет живых каналов.** Для кампаний-наград Twitch не помечает каналы флагом Drops — приложение ищет любой живой стрим категории; если категория пустая, фарм запустится позже.

## Обновления

Настройки → Обслуживание → «Проверить обновления»: приложение смотрит последний релиз на GitHub и, если версия новее, предлагает скачать и установить. Обновление скачивается в временную папку, применяется после закрытия приложения и перезапускает его; файлы профиля (`data/`) не затрагиваются.

## Legacy

В репозитории остаётся старая Electron-версия (`src/main`, `src/core`, `scripts/build.mjs`) — она больше не поставляется, актуальное приложение собирается из `rust/tauri-app`.
