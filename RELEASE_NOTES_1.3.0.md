# DropForge 1.3.0

Первый публичный релиз.

## Возможности

- автофарм Twitch Drops: выбор игр, поиск живого стрима, поддержание сессии просмотра;
- автоматическое получение наград;
- локальные дропсы каналов;
- вкладка **«Бейджи»**: бесплатные и платные значки профиля, статус «получен», кнопка фарма, переход в категорию;
- очередь игр с приоритетом «скоро заканчивается»;
- трей, автополучение, настройки.

## Новое в 1.3.0

- **Диагностика** (Настройки → Обслуживание): собирает версию, ОС, WebView2, наличие сервисов, состояние входа, статус, журнал и доступность Twitch/GitHub. Пути и имя пользователя маскируются, токен и логин в отчёт не попадают. Файл: `data/profile/diagnostics/latest.txt`.
- **Проверка обновлений** через GitHub Releases этого репозитория.
- **Установка обновления из приложения**: скачивает архив релиза, применяет и перезапускается.

## Установка

- `DropForge-1.3.0-win64.zip` — портативная версия;
- `DropForge_1.3.0_x64-setup.exe` — установщик для текущего пользователя.

Требования: Windows 10/11, WebView2 (в системе по умолчанию).
