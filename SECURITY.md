# Безопасность DropForge

## Что сделано

- **Токен Twitch шифруется на диске** через DPAPI (`data/profile/tauri-auth.json`, вид `enc:…`). В логи не попадает.
- **Токен не передаётся в командной строке**: дочерние сервисы (`watcher-svc`, `pubsub-svc`) получают его первой строкой stdin.
- **Ссылки открываются через `ShellExecuteW`**, без `cmd`, только `http(s)`; управляющие символы в URL отклоняются.
- **CSP** в конфиге Tauri и в мете страницы: скрипты только свои, внешние соединения запрещены, картинки только с `static-cdn.jtvnw.net`.
- **XSS-защита**: все внешние строки экранируются.
- **Отладочные хуки** (подмена профиля, путей к сервисам, инъекция токена) в релизной сборке отключены.
- **Нет** сетевых слушателей, автозапуска, задач планировщика и записей в реестр.
- **Нет зависимостей в рантайме** — только упаковка и сборочные инструменты.

## Модель доверия

Приложение доверяет:

- **Twitch API** (`gql.twitch.tv`, `id.twitch.tv`, `usher.ttvnw.net`, `spade.twitch.tv`) — источник данных о кампаниях, прогрессе и наградах;
- **публичному каталогу сообщества** (`drops.sunkwi.com` и снапшот на GitHub) — список кампаний. Подмена этого фида может показать неверные названия и ссылки, но не даёт доступа к аккаунту;
- **GitHub Releases** — обновления скачиваются только из этого репозитория.

Приложение **не** отправляет токен ни на один сторонний адрес.

## Обновления

Проверка идёт через GitHub API этого репозитория. Скачивается архив релиза, применяется локально, приложение перезапускается. Подписи у файлов нет — целостность можно проверить только по SHA256 из описания релиза.

## Как сообщить об уязвимости

Откройте приватный security advisory: `Security` → `Advisories` → `New draft advisory`, либо напишите владельцу репозитория. Не публикуйте детали в открытых issue до исправления.
